# Diccionario de Datos
Breve descripción de las tablas principales.
- **Edicion**: Guarda información del congreso.
- **Persona**: Entidad padre para asistentes y ponentes.
- **Sesion**: Entidad padre para charlas y talleres.
- **Inscripcion**: Tabla asociativa entre Asistente y Sesion.
- **AsignacionPonente**: Tabla asociativa entre Ponente y Sesion.
- **Prerrequisito**: Tabla asociativa recursiva de Sesion.
